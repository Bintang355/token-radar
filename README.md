Token Launch Radar: ranks pre-token DeFi protocols by implied launch value. It reads a sealed DefiLlama snapshot, keeps every protocol with no token that is not a wrapped or staked product of one that trades, and prices each by a category comparable multiple (median mcap/TVL of live-token protocols in the same category) times growth and maturity factors. The dashboard shows the ranked board, a detail view per protocol with the implied-value breakdown and comparables, and a 7-step farm plan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```
